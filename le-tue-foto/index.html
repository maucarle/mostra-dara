Come ordinare

Basta un messaggio. Nessun modulo, nessuna complicazione.

1

Scegli la tua fotografia

Ogni donna della mostra ha una cartella numerata. Indica il numero della tua cartella e, se ricordi, una descrizione dello scatto che vuoi.

2

Scegli formato o file

Indica il formato di stampa oppure se preferisci il file digitale. Puoi ordinare più stampe o più file nella stessa richiesta.

3

Scrivici

Manda un messaggio WhatsApp o una email a info@elisabettacquaviva.it. Ti risponderemo entro 24 ore con le istruzioni per il pagamento e la consegna.

4

Consegna

I file digitali vengono inviati via email entro pochi giorni. Le stampe vengono spedite o ritirate direttamente in mostra — lo decidiamo insieme.
